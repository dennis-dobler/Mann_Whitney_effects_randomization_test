# Mann_Whitney_effects_randomization_test
Randomization tests for hypotheses about multivariate marginal Mann-Whitney effects based on multivariate ordinal one-sample data potentially subject to random missingness (missing completely at random; MCAR)

The file minimal_example.R contains applications to two data sets which are contained in the files cody.rda (one-factorial) and simulated_twofactor.rda (two-factorial).
It uses the functions from the file Mann_Whitney_effects_functions.R (implemented in R) which itself uses functions from the file helpers.cpp (implemented in C++).
